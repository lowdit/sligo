Studio **Sligo** (exampleSite) — chaque vignette ouvre une présentation de démonstration.

Le deck **Catalogue des compositions Sligo** liste une slide par type de bloc YAML (`part`, `focus`, `cards`, `steps`, `stats`, `compare`, `aside`, `radial`, `code`, `quiz`, etc.) ; les autres decks montrent des exemples thématiques qui les combinent.
